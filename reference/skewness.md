# Calculate the skewness of a vector

Moment-ratio skewness \\g_1 = m_3 / m_2^{3/2}\\, where \\m_k\\ is the
\\k\\-th sample central moment (with divisor \\n\\).

## Usage

``` r
skewness(y)
```

## Arguments

- y:

  `numeric` vector of values

## Value

`numeric` scalar of skewness
